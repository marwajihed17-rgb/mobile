Key Interactions

Primary user interactions and their expected behaviors.

Login

User enters credentials → Validates with shake animation on error → Redirects to modules on success

Module Selection

Click module card → Card hover effect with arrow reveal → Navigate to chat interface with module context

Send Message

Type in input → Enter or click send → Message appears with slide animation → Typing indicator shows → Bot responds

File Upload

Click attachment button → Select files → Preview with progress bar → Send with message

User Management

Click user row → Expand with slide animation → Toggle permissions → Delete with confirmation
